# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio built with **React** and **TailwindCSS**. Designed and developed from scratch to showcase projects, skills, technical experience, education, and certifications with a sleek, cyber-inspired design aesthetic.

## ✨ Key Features

- **Interactive Hero Section:** Developer introduction featuring a robot, a dynamic status badge and a code status indicator.
- **About & Philosophy Section:** Showcases professional background, core engineering philosophy, and a direct PDF resume download option.
- **Experience Timeline:** Structured visual timeline detailing past roles, tenure, key achievements, and technical contributions across engineering projects.
- **Selected Projects Showcase:** Interactive cards highlighting projects like _Frequency X_ and _Tourvisto_ with metadata, tags, and detail view modals.
- **Education & Certifications:** Dedicated highlights for academic background (Integrated Master in Information and Electronic Engineering) and industry certifications (e.g., NiDS2025 conference).
- **Contact & Social Hub:** Direct email access (`alexoiik2001@gmail.com`) alongside quick-link integrations for GitHub and LinkedIn.
- **Responsive Navigation:** Sticky header with active state tracking (`About`, `Experience`, `Projects`, `Contact`) and mobile menu support.
- **Micro-Interactions:** Smooth hover animations, glowing neon accents, and reactive UI feedback loop.

## 👨‍💻 My Contribution & Development Approach

As the sole designer and developer on this project, I handled the end-to-end product lifecycle from preliminary wireframing in Figma to final production deployment:

1. **Design System:** Created a cohesive, dark-mode cyber aesthetic with distinct neon blue accents, custom status indicators, and clean typography.
2. **Component Architecture:** Built modular, reusable React components prioritizing clean code, maintainability, and scalability.
3. **Data-Driven Architecture:** Structured project, timeline, education, and certification metadata into centralized datasets for seamless rendering and effortless content updates.
4. **Responsive Execution:** Utilized TailwindCSS mobile-first utility patterns to ensure fluid, high-performance rendering across all screen breakpoints.
